## Folders

- `pages/<page>/`: design previews. Open `index.html` in a browser to compare the options.
- `upload/<page>/<option>/`: files to paste into Sitefinity. These are generated by `node tools/build-sitefinity.mjs CCM/pages/<page>`, so don't edit them by hand.
