## Clean-up candidates

Many addresses are inconsistent. Some pages sit at the top level when they belong under a section, for example `/bsinmathematics` and `/msinmathematics`. Others:
- one address contains the domain name: `/math.kfupm.edu.sa/cx-programs-…`
- one has a typo and an apostrophe: `/chairmn's-message`
- one uses a different name from its page: `/ProgramMissionandObjectives` (Actuarial Science)

Changing addresses breaks old links, so plan redirects before renaming anything.
